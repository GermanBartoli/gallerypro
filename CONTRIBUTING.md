# Cómo contribuir

1. Describí el problema y el comportamiento esperado sin adjuntar fotos, identificadores, cookies, tokens ni respuestas privadas.
2. Mantené los cambios pequeños y separados entre integración, núcleo e interfaz.
3. Usá español para documentación, comentarios y mensajes al usuario.
4. Agregá pruebas con datos ficticios cuando cambie la clasificación o el protocolo.
5. Ejecutá `npm test` y `npm run build`; verificá en Chrome los cambios visuales.
6. Conservá CRLF según `.gitattributes` y revisá `git diff --check`.

No agregues dependencias, permisos ni operaciones de escritura sin discutir antes el alcance. No publiques capturas de bibliotecas personales como evidencias.
